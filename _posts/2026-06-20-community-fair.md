# Mini Games

There were three types of mini games: Slot Machines, Lockpicking, and Memory

## Slot Machines

The Slot Machine game consisted of 3 volunteers cycling between different colors of balloons. The participant would tell them Go and then Stop. If the colors all matched or were all different, the participant would win a prize!

Hosted by: Locks and KupoMog, with slot machine volunteers thevoid, Euphrosyne, Saeris, Tempes, Onyxa, chantie

![slot machines](https://darkages-screenshot-archive.s3.us-east-1.amazonaws.com/events/community-fair-2026/slot-machines.png){: width="100%" }

## Lockpicking Game

The Lockpicking game had four different fior items configured in a specific order, and participants were tasked with guessing the order. The host would give clues such as "One correct" or "Two correct", without specifying which exact fiors so that participants could tell if they were getting closer.

Hosted by: Trovosky

![lockpick game](https://darkages-screenshot-archive.s3.us-east-1.amazonaws.com/events/community-fair-2026/lockpick-game.png){: width="100%" }

## Memory Game

The Memory game involved revealing pairs of concealed items on a grid, and trying to match up pairs of identical items

Hosted by: Dram

![memory game](https://darkages-screenshot-archive.s3.us-east-1.amazonaws.com/events/community-fair-2026/memory-game.png){: width="100%" }
